# S3

The `methodaws s3` family of commands provide information about an account's S3 buckets and their contents.

## Usage
```bash
methodaws s3 [command]
```

## Available Commands
- **enumerate**: Gather information about all S3 buckets the provided credentials have access to
- **list**: List all objects in a single S3 bucket
- **external**: Enumerate a public facing S3 bucket from an external perspective

## Commands

### Enumerate

The enumerate command will gather information about all of the S3 buckets that the provided credentials have access to.

#### Access and Encryption Signals

`configuration.accessControl.allowPublicList` describes bucket-level listing permissions from the collected ACL and policy.
`allowPublicRead` describes object-read permissions from the bucket policy, not listing or individual object ACLs.
Bucket ACL `READ` and `FULL_CONTROL` grants populate listing permissions, including `allowAuthenticatedUsersList` for the
AuthenticatedUsers group. These are configuration assessments, not proof of successful access to every object.

Each encryption rule retains the reported `kmsKeyIdentifier`, including aliases and bare key IDs. The separate `kmsKey`
reference is populated only for a concrete key ARN; aliases are not resolved or treated as key ARNs.

#### Usage

```bash
methodaws s3 enumerate --regions us-east-1 --output json
```

### external

The external command attempts to enumerate a public facing S3 bucket with anonymous credentials from an external perspective.

`allowDirectoryListing` and `allowAnonymousRead` report anonymous probe results. Entries in `acls` describe the returned
bucket ACL grants, not effective access after all applicable controls. A missing bucket policy is normal; failed optional
policy or ACL requests are reported without discarding the identified bucket.

#### Usage

```bash
methodaws s3 external --url https://bucketname.s3.amazonaws.com --output json
```

#### Help Text

